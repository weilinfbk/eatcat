# 吃掉小猫猫 - Material 3 重制版 (Eat the Cat - M3 Edition)

本项目 Fork 自 [122440367/eatcat](https://github.com/122440367/eatcat)。在保留原版核心玩法（新概念音游）与底层逻辑的基础上，对整个游戏进行了全面的 **Material Design 3 (M3)** 视觉重构、体验优化以及国际化支持。

## ✨ 主要改造与修改内容

### 1. 视觉与 UI 重构 (Material 3)
- **全面适配 Material 3 设计语言**：引入 M3 的色彩系统（Design Tokens）、圆角规范（胶囊按钮、芯片）和阴影层级。
- **系统级深浅色自动跟随**：使用 CSS `@media (prefers-color-scheme)` 实现自动跟随系统亮/暗色模式。
  - **暗色模式**：深空灰背景搭配浅紫色主色调，高级且护眼。
  - **亮色模式**：采用浅紫灰背景与纯白毛玻璃卡片，提升层次感，解决纯白刺眼问题。
- **组件重绘**：将原有的 Bootstrap 按钮重绘为 M3 填充按钮（Filled）、色调按钮（Tonal）、描边按钮（Outlined）及芯片（Chips）；输入框改为浮动标签（Floating Label）样式；复选框重绘为 M3 Switch。

### 2. 游戏内视觉优化
- **网格与轨道**：方块改为半透明玻璃卡片质感，奇偶轨道透明度区分，增加音游判读纵深；点错时红色反馈更柔和。
- **悬浮时间胶囊**：剩余时间从纯文本改为带毛玻璃效果的悬浮胶囊（Capsule），居中显示，字号加大。
- **自定义图片即时生效**：修复了选择自定义按键图片后，需要重开游戏才生效的问题。

### 3. 逻辑 Bug 修复与体验优化
- **修复 NaN 结算 Bug**：修复了未点击任何音符直接阵亡时，结算界面显示“坚持了 NaN 秒”的底层计算错误。
- **解决快速点击闪屏/连击问题**：引入 GPU 硬件加速（`will-change: transform`），并在点击事件中加入 30 毫秒防抖（Debounce），杜绝高频点击导致的闪屏和判定连发。
- **解决页面滑动干扰**：锁定网页全局滚动（`touch-action: manipulation`），防止在手机上快速游玩时误触浏览器缩放或滑动页面。
- **修复刷新死链**：修复了原版“出现了 bug 刷新”按钮点击无反应的问题，现在会清除数据并强制重载。

### 4. 国际化 (i18n)
- **系统语言自适应**：通过读取 `navigator.language` 自动判断玩家系统语言。
- **双语支持**：如果系统语言为英文，游戏主界面、设置、动态倒计时、结算评语（如 BPM 数据、评语等）将自动无缝替换为英文，无需玩家手动切换。

## 🚀 如何体验
你可以直接访问 GitHub Pages 链接游玩，或者将代码拉取到本地直接用浏览器打开 `index.html` 体验。
